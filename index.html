02 / SQL & dimensional modelling

Sales Data Warehouse Design

Business question: How can transactional sales be organised into a consistent reporting model for revenue, cost, product, region and customer-segment analysis?

Method: Create a MySQL 8+ star schema with a sales fact table and date, product, region and customer dimensions. Use joins, grouped aggregations, CTEs and LAG() for analytical queries.

MySQL 8+Star schemaCTEsWindow functions
Seed records are synthetic and used to demonstrate the model. This is a SQL modelling project, not a hosted production database.
