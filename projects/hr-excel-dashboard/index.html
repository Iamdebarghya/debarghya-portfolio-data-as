Advanced Excel

This project is an Excel-based workforce reporting workbook. The repository also contains a data dictionary template and a browser-based file exploration demo. The workbook itself is the primary artefact; the notes below describe what can be verified from the repository documentation.

Questions the report is intended to support

  • How is the workforce distributed across departments?
  • How do employee counts vary across the categories available in the source?
  • What do salary summaries show, if salary data is present?
  • How do performance categories compare, if a rating field is present?

These are review questions, not confirmed findings. The repository documentation asks the reviewer to confirm the actual fields in the workbook before interpreting them.

Workbook review process

  1. Open the original workbook in Microsoft Excel desktop.
  2. Inspect the available sheets and identify the source-data range.
  3. Check which PivotTables, charts and slicers are actually present.
  4. Verify the source fields, category labels, salary units and rating scale.
  5. Refresh PivotTables after any source-data change, then reconcile totals.

Data quality checks to perform

  • Check blank and duplicate employee identifiers.
  • Check missing department and salary values.
  • Confirm salary currency and pay frequency.
  • Confirm the performance-rating scale and missing-value meaning.
  • Keep employee-level information private.

The repository's DATA_DICTIONARY.md is explicitly a template. Its suggested fields are not proof that those fields exist in the workbook.

Limitations

The repository README describes a browser demo for grouped summaries from an uploaded Excel or CSV file. It is not a replacement for Excel PivotTables. No business KPI or workbook field is claimed here until it has been checked directly in the workbook.
