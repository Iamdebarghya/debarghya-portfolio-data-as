Sales Data Warehouse Design

A MySQL 8+ dimensional modelling project that organizes transactional sales data into a star schema for BI reporting and analytical SQL. The repository includes schema creation, small synthetic seed data and example business queries.

Project objective

Build a consistent reporting layer for revenue, cost, gross profit, product performance, regional contribution and customer-segment analysis.

Analytical SQL included

  • Monthly revenue, cost and gross profit
  • Regional revenue contribution
  • Product performance and gross profit
  • Customer segment and average order value
  • Month-over-month growth using LAG()
  • Discount and gross margin by category

How to run

  1. Use MySQL 8+ in a local development environment.
  2. Run schema.sql to create and seed sales_warehouse.
  3. Run the statements in queries.sql.
  4. Reconcile totals before using the model for real reporting.

Tools and limitations

MySQL 8+, SQL DDL, dimensional modelling, joins, aggregations, CTEs and window functions. Seed data is synthetic and intended to demonstrate the schema and queries. Tax, returns and shipping treatment would need confirmation for a real source.
