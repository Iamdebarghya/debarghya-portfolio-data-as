Sales Data Warehouse Design

This is a small sales warehouse built in MySQL 8+. It has one sales fact table and four dimension tables. The repository contains the table definitions, five sample sales rows and six example queries.

Project objective

The model separates sales measures from date, product, region and customer details so they can be queried together for reporting.

Queries in queries.sql

  • Monthly revenue, cost and gross profit
  • Regional revenue contribution
  • Product performance and gross profit
  • Customer segment and average order value
  • Month-over-month growth using LAG()
  • Discount and gross margin by category

Run the SQL locally

  1. Use MySQL 8+ in a local development environment.
  2. Run schema.sql to create and seed sales_warehouse.
  3. Run the statements in queries.sql.
  4. Reconcile totals before using the model for real reporting.

Tools and project notes

The project uses MySQL 8+, primary and foreign keys, joins, aggregations, a CTE and LAG(). The five sample sales rows are synthetic. Before applying this model to company data, define how tax, returns, shipping and discounts should be treated.
